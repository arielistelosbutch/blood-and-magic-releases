# Blood & Magic Reimagined

Unofficial fan remaster of **Blood & Magic** (1996, Tachyon Studios / Interplay) for modern Windows, with an optional Czech translation.
Made by **Ivo "Arielistelos" Florek**.

**Download (1.1.2):** [installer](downloads/BloodAndMagic_Reimagined_1.1.2_Setup.exe?raw=1) · [ZIP](downloads/BloodAndMagic_Reimagined_1.1.2.zip?raw=1) · [what's new / co je nového](notes_1.1.2.md)

**You need your own original Blood & Magic CD (or a CD image).** No original game data is included; on the first run the game finds your CD / image and copies the data it needs.

The game checks this repository for new versions at start-up and offers them in the main menu (never forced). Bugs: press **F7** in the game, or open an [issue](../../issues).
